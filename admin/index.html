💡 সার্ভার কানেক্ট করতে না পারার মূল কারণ ও সমাধান:

১. আপনার হোস্টিংয়ে (cPanel / Shared Hosting / VPS) মূল ডিরেক্টরিতে api.php, upload.php এবং data/ ফোল্ডারটি আপলোড আছে কিনা নিশ্চিত করুন।

২. data/ এবং assets/uploads/ ফোল্ডার দুটির পারমিশন 755 বা 777 (Writable) থাকতে হবে যাতে সার্ভার ডাটা সংরক্ষণ করতে পারে।

MySQL ডাটাবেজ লিঙ্ক করার ২ টি সহজ পদ্ধতি:

পদ্ধতি ১: ড্যাশবোর্ড থেকে অটোমেটিক লিঙ্ক (সবচেয়ে সহজ):
  1. ইউজারনেম Tarique এবং পাসওয়ার্ড #Tarique-1998 দিয়ে লগইন করুন।
  2. বামপাশের মেন্যু থেকে "ডাটাবেজ ও ব্যাকআপ" ট্যাবে যান।
  3. আপনার cPanel থেকে তৈরি করা MySQL Host (localhost), Database Name, User ও Password লিখুন।
  4. "টেস্ট কানেকশন" বাটনে ক্লিক করে সংযোগ সফল হলে "ডাটাবেজ সিঙ্ক (Push)" করুন। এতে প্রয়োজনীয় সব টেবিল অটো তৈরি হয়ে যাবে!
পদ্ধতি ২: হোস্টিং ফাইল ম্যানেজারে db_config.php এডিট করে ম্যানুয়াল লিঙ্ক:

cPanel File Manager থেকে প্রজেক্টের রুট ফোল্ডারে থাকা db_config.php ফাইলটি ওপেন করে আপনার ডাটাবেজের নাম ও পাসওয়ার্ড বসিয়ে দিন।

২. MySQL থেকে ডেটা লোড করুন MySQL ➜ অ্যাপ

MySQL ডাটাবেজ থেকে সকল ডেটা অ্যাপ্লিকেশনে লোড করে সিঙ্ক করবে।

cPanel / phpMyAdmin সেটআপ টিপস

  • উপরে .SQL স্ক্রিপ্ট ডাউনলোড বাটনে ক্লিক করে পুরো ডাটাবেজ ফাইলটি নামিয়ে নিন।
  • আপনার cPanel-এর phpMyAdmin এ গিয়ে Import ট্যাবে ক্লিক করে ফাইলটি আপলোড দিন।
  • অথবা সরাসরি লোকালহোস্ট XAMPP-এ aspi_polytechnic_db নামে ডাটাবেজ বানিয়ে ইমপোর্ট করুন।
